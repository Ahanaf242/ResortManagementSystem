Run in NetBeans:
1. Open the ResortmanagementSystem project folder.
2. Select Clean and Build.
3. Select Run Project.

Run the built JAR:
java -jar dist/ResortmanagementSystem.jar

Booking date format:
yyyy-MM-dd

Example:
Check-in: 2026-08-15
Check-out: 2026-08-18
Days: 3

Important:
Application data is shared between all open GUI windows during one program run.
The current assignment project stores data in memory, so data resets after the
application is closed.
